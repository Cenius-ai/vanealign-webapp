== 3. Eyepieces: 900 mm telescope, a 25 mm Plossl and a 9 mm Nagler

$ vanealign eyepieces focal 900
  Telescope focal length is now 900 mm.

$ vanealign eyepieces add --label "25mm Plossl" --fl 25 --afov 50
  Added eyepiece 1: 25mm Plossl (36.0x, 1.39° true field).

$ vanealign eyepieces add --label "9mm Nagler" --fl 9 --afov 82
  Added eyepiece 2: 9mm Nagler (100.0x, 0.82° true field).

$ vanealign eyepieces

  Eyepieces ──────────────────────────────────────────────────────────
  telescope focal length 900 mm

  no.  label                     focal    afov      mag true field
  ---------------------------------------------------------------
  1    25mm Plossl             25.0 mm   50.0°    36.0x      1.39°
  2    9mm Nagler               9.0 mm   82.0°   100.0x      0.82°
  ────────────────────────────────────────────────────────────────────
  Add with `vanealign eyepieces add`, or run `vanealign` for the menu.

== 4. Notes: M31 logged first, M42 logged second - newest observation lists first

$ vanealign notes add --object M31 --date 2024-10-01 --rating 3 --body "core bright, dust lanes soft at 120x"
  Added note for M31 on 2024-10-01 (seeing 3/5).

$ vanealign notes add --object M42 --date 2024-11-02 --rating 4 --body "Trapezium split cleanly at 120x, E star suspected"
  Added note for M42 on 2024-11-02 (seeing 4/5).

$ vanealign notes

== 5. Validation refuses bad input without writing anything

$ vanealign align toggle 9
vanealign: Step must be between 1 and 7.
(exit status 1 - the checklist is unchanged)

$ vanealign eyepieces add --label "7mm Ortho" --fl 0 --afov 45
vanealign: Eyepiece focal length must be a number greater than 0.
(exit status 1 - nothing was added)
